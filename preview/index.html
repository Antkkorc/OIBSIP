Five Android apps,
one glass surface.

Everything below runs in the browser, but the layout, colours and timing are the same ones in the Android source. Tap a chip, type a number, finish a quiz. Each phone is a working copy of a screen that ships in this repository.

  • Java + XML
  • minSdk 26
  • 54 unit tests
  • No UI kit

Tip: the button in the top right switches the whole page, apps included, to the light palette.

Task 01

Unit converter

Four categories, twenty-six units. Length, weight, volume and temperature all sit behind the same two spinners, so switching category swaps the unit lists and clears the old answer instead of leaving a stale number on screen.

  • Empty or non-numeric input shows a toast and a line under the result.
  • Commas work as decimals, and a value below absolute zero is refused.
  • Long press the result on Android to copy it.

Task 02

Task list with login

Register, sign in, and every task you add belongs to that account only. Passwords are stored as PBKDF2-HMAC-SHA256 with a per-user salt, not as text. Logging out clears the session, so the next person to open the app sees the sign-in screen.

  • Tick a task to strike it through. Delete asks first.
  • Filters for all, open and done, plus a count line up top.
  • This copy keeps accounts in memory while the page is open.

Task 03

Calculator

The tape is a list of numbers and operators, not a raw string, so fast or repeated taps can only build a valid expression. A second operator replaces the first, and the equals key never sees a trailing one.

  • Multiplication and division before addition and subtraction.
  • Divide by zero prints Error, and the next key starts clean.
  • Results group by thousands and switch to scientific notation at the extremes.

Task 04

Quiz

Ten questions from a larger bank, dealt in a new order each run. The first tap locks your answer: the right option turns green, a wrong pick turns red, and the note underneath explains it before you move on.

  • Progress bar, question counter and a running score.
  • Results screen counts correct, incorrect and accuracy, then deals again.
  • Rotating the phone keeps your place, not your streak.

Task 05

Stopwatch

Hundredths, built on the device clock rather than a counter, so the time is right after a pause, a rotation or an hour in the background. Laps record splits and mark the fastest and slowest of the run.

  • Start, pause, resume and reset, each dimming when it has nothing to do.
  • Laps list keeps the newest at the top.
  • The screen stays awake while the clock runs.

Build any of them

Open the project folder in Android Studio, let Gradle sync, and press Run. Each folder is a standalone app with its own README, and the step by step version with the exact paste points is in docs/BUILD_AND_RUN.md.
